## Как проверить

1. Введите «берег» и нажмите «Показать маршруты». Останется «Сосновый берег». Добавьте «Горы» и снова примените фильтр: совпадений нет.
2. Сбросьте условия, выберите лёгкую прогулку до трёх часов. Подойдут три маршрута.
3. Сохраните один маршрут, обновите страницу и откройте «Мои маршруты». После удаления последнего маршрута появится сообщение о пустом избранном.
4. Введите больше 80 символов в поиск. Поле покажет ошибку. Сократите запрос, чтобы продолжить.
5. Раскройте памятку перед прогулкой повторным нажатием на её заголовок: она открывается и закрывается.

Карточки загружаются из [data/data.json](data/data.json). В [index.html](index.html) оставлен один пустой шаблон. Загрузка, вывод карточек и обработчики поиска, фильтров и избранного находятся в [js/script.js](js/script.js). Памятка использует встроенный элемент HTML `details`.

Чтобы проверить сбой загрузки, заблокируйте запрос к `data/data.json` в DevTools и обновите страницу. Снимите блокировку и нажмите «Загрузить ещё раз». Каталог восстановится без перезагрузки страницы.

## Локальный запуск

Откройте папку в VS Code и выберите **Open with Live Server** для `index.html`. Ещё один вариант при установленном Node.js — `npx live-server --host=127.0.0.1`. Для `fetch` нужен HTTP-сервер.

## Комментарий к вёрстке

На компьютере в ряд помещаются три маршрута, на планшете два, на телефоне один. Самым тесным местом оказалась форма: на телефоне поля стоят друг под другом, а варианты местности переносятся на следующую строку.

Вопрос для консультации: при открытии избранного лучше сохранить активные фильтры или сразу показать все сохранённые маршруты? Сейчас сохраняются условия последнего поиска.

Маршруты демонстрационные. Фотографии иллюстративные.

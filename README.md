## Функции

Якорные ссылки ведут к разделам страницы. Форма ищет по названию или месту и применяет выбранные фильтры совместно. Диапазон времени сравнивается по верхней границе. Кнопка сброса возвращает все маршруты. Памятка раскрывается стандартным элементом HTML.

Для проверки выберите «До 3 часов» и «Лёгкий»: останутся три маршрута. Запрос «берег» и местность «Горы» дадут пустую выдачу.

## Файлы

- `index.html` — семантическая разметка и шесть статических карточек.
- `css/style.css` — базовое оформление и адаптация к узкому экрану.
- `js/script.js` — обработка формы. Карточки доступны и без скрипта.
- `data/data.json` — данные шести маршрутов для следующего этапа.
- `images/` — иллюстративные фотографии из макета (Unsplash).
- `docs/screenshot.jpg` — скриншот страницы.

Маршруты демонстрационные.

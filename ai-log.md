# Журнал работы с ИИ

**Проект:** Тропа. **Дата обращения:** 26 ноября 2026 года. **Инструмент:** OpenAI Codex.

**Запрос:** «Убери из сайта все вот эти подзаголовки которые нейронки как ты любят добавлять и которые не привносят ничего нового, также сделай все из этих заданий и опубликуй через гитхаб пейджес». К запросу приложены TASK 5.pdf и TASK 6.pdf.

## Практическая работа № 5

**Задача.** Сохранить поиск, выбор параметров и избранное при переходе от статических карточек к динамическим. Убрать подпись поверх фотографии и фразы, которые повторяют заголовки.

**Результат и логика.** Кнопка «Показать маршруты» считывает заполненные поля. Поиск сравнивает введённый текст с названием и местом, а фильтры проверяют время, сложность и местность. Маршрут остаётся в списке, если подходит по всем условиям. Кнопка сохранения добавляет название в избранное или удаляет его при следующем нажатии. Список хранится в браузере и доступен после обновления страницы.

**Проверка.** На мобильной ширине 390 px запрос «берег» дал один результат. При выборе «Горы» список опустел. После сброса вернулись шесть карточек. Лёгких маршрутов до трёх часов оказалось три. Проверены сохранение, повторное открытие сайта и удаление из избранного, ошибка при запросе длиннее 80 символов и повторные нажатия на памятку. [Демонстрация](docs/demo.gif).

## Практическая работа № 6

**Задача.** Загружать шесть маршрутов из JSON при открытии страницы и показывать понятное сообщение при сетевой ошибке.

**Результат и логика.** Функция загрузки запрашивает файл через fetch, проверяет ответ и читает массив. Для каждого подходящего маршрута скрипт копирует один HTML-шаблон, заполняет название, фотографию, описание и параметры, затем добавляет карточку в каталог. При сетевой ошибке вместо карточек появляется сообщение и кнопка повтора.

**Проверка.** В обычном сеансе JSON вернул HTTP 200, консоль сообщила о загрузке шести маршрутов. В отдельном тестовом сеансе запросу к JSON вернули HTTP 503: сайт показал ошибку. После снятия подмены кнопка повтора восстановила список. На опубликованном сайте повторно проверены загрузка, поиск, фильтры и избранное. [Скриншот консоли](docs/console.png).
